# YUE Dream

> 用 AI 做一本属于你自己的《红书》。

荣格曾用十多年记录梦、幻想、绘画与内在对话，最终留下了《红书》。它不是一本公共解梦词典，而是一部由个人生命材料逐渐长成的内在作品。

YUE Dream 受这一理念启发，把原本漫长、困难的梦境记录与内在对话，变成普通人也能开始的 AI 对话：

```text
讲出一个梦
→ AI从细节里找出贯穿结构
→ 你用真实感受确认或推翻
→ 多次对话逐渐长成自己的红书
```

第一次只需要贴出梦境。YUE Dream 会先给出一份完整解释：从情绪、身体感、人物关系、行动顺序和现实余波中，选择最能覆盖多个片段的结构，再沿梦境细节证明它。后续对话由你参与校准，而不是让AI替你宣布真相。

它不使用固定解梦词典，不预测未来，也不会把 AI 的解释当成你的真相。

## 电脑端安装

适用于 Codex、Claude Code、Qwen Code、TRAE CN 等支持 Agent Skills 的电脑端 Agent：

```text
npx -y skills add yuez35001-debug/yue-dream -g --all
```

安装后直接说：

```text
使用 $yue-dream 深度解释这个梦：先找出覆盖力最强的结构并用细节证明，再通过问题让我参与校准。
```

你不需要整理梦境，也不需要填写表格。记得一句，就讲一句；记得很多，就按原来的顺序讲。豆包等不支持 Agent Skills 的普通聊天产品不能使用这条安装命令。

## 普通AI与手机智能体

把 [`prompts/YUE_DREAM_3.1.md`](prompts/YUE_DREAM_3.1.md) 复制到支持系统提示词的智能体平台，再从文件末尾粘贴梦境。它适合扣子等手机智能体的快速测试，也可以直接与梦境一起交给普通AI。

## 为什么不是普通解梦？

普通解梦经常直接告诉你：蛇代表什么、掉牙代表什么、梦见前任说明什么。

YUE Dream 更关心：

- 梦里是谁在推动事情，谁在决定节奏？
- 你是主动选择、被带领、抗拒、享受，还是来不及反应？
- 哪个时刻从新鲜变成害怕，从游戏变成现实？
- 进入之前你知道什么，代价又是在什么时候出现的？
- 这与最近的关系、工作、创作和身体感受有什么连续性？

3.1 版本会先在内部比较多个候选结构，只呈现覆盖梦境片段最多、额外假设最少的主线；若梦里确实存在两条主线，也不会为了制造一句金句而强行合并。

AI先给出有细节依据的完整解释，再由你决定哪些解释有感觉、哪些完全不对。你的震惊、委屈、感动和反驳都会成为下一轮探索的材料。

## 即使只记得一句梦，也可以开始

比如你只记得：

> 我梦到前女友和我复合了。

YUE Dream 不会立刻宣布“你还爱她”。它会陪你分辨：是谁提出复合、你当时是什么感觉、梦停在了哪里，以及最近有什么现实经历重新激活了这段关系。

一个很短的梦，也可能照见一种关系模式、一项被低估的优势、一个没有被承认的需要，或者一个正在成形的人生方向。

## 从一次梦境，到一本自己的红书

一次解梦只能带来一个片段。多次经过你确认的对话，才可能显出真正属于你的重复母题：

- 总在梦里出现的人；
- 不断变化的房间、道路或身体感；
- 你如何从被动变成询问、拒绝和选择；
- 同一种冲突如何在现实中发生变化；
- 哪些能力和需要一直存在，却没有被白天的你承认。

YUE Dream 会逐步把这些内容整理为：

```text
梦境碎片
→ 个人梦境地图
→ 母题与变化轨迹
→ 个人红书第一卷
```

个人红书不是 AI 写给你的人格报告。它由你的原始梦境、关键原话、现实经历、确认过的发现和仍未回答的问题共同长成。

## 一次完整探索可能带来什么？

- 看见过去没有被清楚命名的行为模式；
- 发现某个问题背后也藏着优势；
- 照见事业与享受、控制与被带领、安全与冒险等核心矛盾；
- 识别休息、被选择、被照顾、表达、自主或边界等需要；
- 选择自己真正想继续探索的方向；
- 把梦境发现发展成文章、视频、图像或个人目标。

YUE Dream 不会在你刚产生感觉时，突然让你开始打卡填表。AI负责整理，方向由你选择。

## 边界

YUE Dream 是自我探索工具，不是心理治疗、医学诊断或预言工具。梦境不能证明现实事件发生过，也不能替你决定关系、投资、医疗或其他重大事项。

涉及持续噩梦、明显睡眠困扰、创伤反应或安全风险时，请寻求合格的心理健康、睡眠医学或当地紧急支持。
