# YUE Dream

> 用 AI 做一本属于你自己的《红书》。

1913年冬，荣格开始有意识地进入幻想活动，并把材料记录在后来被称为《黑书》的笔记中。随后，他反复整理、阐释、誊写和绘制这些材料，形成了通常标注为1914—1930年的《红书》（*Liber Novus*）手稿；1959年他曾尝试补写结语，但作品仍未完成，直到2009年才正式出版。[美国国会图书馆时间线](https://www.loc.gov/exhibits/red-book-of-carl-jung/creation-and-publication-of-the-red-book.html) · [Philemon Foundation 项目说明](https://philemonfoundation.org/works/red-book/)

《红书》不是一本公共解梦词典，也不只是梦境日记。它记录了荣格持续面对、理解和转化内在经验的过程，并以文字、书法和绘画形成一部个人作品。

YUE Dream 受这一理念启发，把原本漫长、困难的梦境记录与内在对话，变成普通人也能开始的 AI 对话：

```text
讲出一个梦
→ AI从细节里找出贯穿结构
→ 你用真实感受确认或推翻
→ 多次对话逐渐长成自己的红书
```

第一次进入时，YUE Dream 会先说清楚它是谁、能帮你得到什么，再由你选择：只是好奇看一个线索、在来回对话中逐渐探索、一次得到完整深度分析，或先把梦保存下来。

你也可以直接贴出梦境。AI 会先用一个细节让你看见“这个梦可能有什么用”，但不会把你发来的梦自动视为“授权完整分析”。

它不使用固定解梦词典，不预测未来，也不会把 AI 的解释当成你的真相。

## 新手使用指南

### 1. 你不需要先学会记梦

直接用你原来的说话方式讲就可以。可以跳跃、重复、记不清，也可以夹着醒来后的想法。

例如：

```text
我只记得牙齿松了，当时特别害怕，一直想怎么补救。
```

或者：

```text
我经常梦到和明星在一起，但具体情节记不清。
```

### 2. AI 会先给你一个有用的发现

YUE Dream 不会一上来就让你回答一长串问题。它应当先从你已经说出的内容里，指出一个与这个梦具体相关的画面、关系动作、情绪转折或重复结构。

比如“经常和明星在一起”里，值得注意的不只是“明星代表什么”，而是梦反复把你从“看明星的人”放到了“可以进入他们世界的人”这个位置。

### 3. 你会知道它可能意味着什么

AI 会根据梦中证据给出最多两条不同的暂定意义。它可能正在整理对某个具体人的吸引，也可能在体验被看见、被选择或与优秀者平等相处的位置。

这些都不是结论，只是等你校准的假设。

### 4. AI 最后只问一个真正有用的问题

这个问题不是为了帮 AI 填补资料，而是用来区分两条不同的理解。

例如：

> 更让你有感觉的，是某个明星本人，还是“我竟然可以自然地进入他们的世界”？

你可以说“前者”“后者”，也可以说“都不对”。你的反驳也是有价值的新材料。

### 5. 你决定接下来走多深

完成第一次校准后，你可以选择：

- **好奇看看**：只再看一个核心线索。
- **聊着探索**：每轮深入一层，在对话中逐渐看清。
- **完整深度分析**：一次获得较多细节模式和现实联系。
- **先记下来**：保留原始梦境，以后再聊。

随时可以改变深度，不需要一开始就决定完整目标。

### 6. 怎样判断一次探索有没有帮助

不只看 AI 说得“准不准”。更值得观察的是：

- 你是否想起了之前遗漏的感受；
- 是否看见了一种以前没有命名的重复模式；
- 是否发现某个“问题”同时也藏着优势或需要；
- 是否在现实关系、工作或创作中出现了一个新选择。

### 7. 想长期使用时

你只负责讲梦、补充感受和做选择；AI 负责整理。多次经你确认的探索，可以逐渐沉淀为：

```text
梦境碎片 → 个人梦境地图 → 母题与变化轨迹 → 个人红书
```

第一次可以直接发送：

```text
新手入门。我记得的梦是：……
```

## 电脑端安装

适用于 Codex、Claude Code、Qwen Code、TRAE CN 等支持 Agent Skills 的电脑端 Agent：

```text
npx -y skills add yuez35001-debug/yue-dream -g --all
```

安装后直接说：

```text
使用 $yue-dream 帮我探索一个梦。先介绍你能带来什么，再让我选择想要的探索方式。
```

你不需要整理梦境，也不需要填写表格。记得一句，就讲一句；记得很多，就按原来的顺序讲。豆包等不支持 Agent Skills 的普通聊天产品不能使用这条安装命令。

## 为什么不是普通解梦？

普通解梦经常直接告诉你：蛇代表什么、掉牙代表什么、梦见前任说明什么。

YUE Dream 更关心：

- 梦里是谁在推动事情，谁在决定节奏？
- 你是主动选择、被带领、抗拒、享受，还是来不及反应？
- 哪个时刻从新鲜变成害怕，从游戏变成现实？
- 进入之前你知道什么，代价又是在什么时候出现的？
- 这与最近的关系、工作、创作和身体感受有什么连续性？

4.0 保留“具体发现 → 可能意义 → 单一校准问题”的顺序，又增加一条更严格的要求：每个追问、理论和现实建议，都必须说清它与用户想要的结果有什么关系。如果只是完善因果故事、满足解释欲或延长对话，就不应优先问。

这个版本也禁止 AI 用一长串关系、情绪或情节选项让你填问卷。“好奇看看”只呈现一个值得注意的线索；“聊着探索”每轮只进入一层；只有你明确选择“完整深度分析”时，AI 才会在一轮中给出较多觉察。

不论哪种方式，AI 的解释都只是暂定假设。你的震惊、委屈、感动、无感和反驳都会成为下一轮探索的材料。

## 从看见，到现实有用

当你已经确认一个发现，并选择把它带回现实，YUE Dream 会把推进变成可检查的闭环：

```text
我想要什么结果
→ 哪个动作可能产生它
→ 我怎么看出它是否真的有用
```

4.0 同时加入 **HUNGER 1.0 试用框架**。它不用来强行解释每个梦，而是在用户确认某个“挂住”后，尝试识别所求体验、直接提供一小部分该体验、观察是否松动，再把回来的能量投入保护、增强、创造或积累。这是待真实对话继续验证和修正的 1.0，不是已被证明的心理治疗理论。

## 即使只记得一句梦，也可以开始

比如你只记得：

> 我梦到前女友和我复合了。

YUE Dream 不会立刻宣布“你还爱她”，也不会连续追问一堆细节。它会先告诉你：“是谁提出复合”会区分“你想回去”与“你想被再次选择”这两条不同的线，然后只问你一个最有用的问题。

一个很短的梦，也可能照见一种关系模式、一项被低估的优势、一个没有被承认的需要，或者一个正在成形的人生方向。

## 从一次梦境，到一本自己的红书

一次解梦只能带来一个片段。多次经过你确认的对话，才可能显出真正属于你的重复母题：

- 总在梦里出现的人；
- 不断变化的房间、道路或身体感；
- 你如何从被动变成询问、拒绝和选择；
- 同一种冲突如何在现实中发生变化；
- 哪些能力和需要一直存在，却没有被白天的你承认。

YUE Dream 会逐步把这些内容整理为：

```text
梦境碎片
→ 个人梦境地图
→ 母题与变化轨迹
→ 个人红书第一卷
```

个人红书不是 AI 写给你的人格报告。它由你的原始梦境、关键原话、现实经历、确认过的发现和仍未回答的问题共同长成。

## 一次完整探索可能带来什么？

- 看见过去没有被清楚命名的行为模式；
- 发现某个问题背后也藏着优势；
- 照见事业与享受、控制与被带领、安全与冒险等核心矛盾；
- 识别休息、被选择、被照顾、表达、自主或边界等需要；
- 选择自己真正想继续探索的方向；
- 把梦境发现发展成文章、视频、图像或个人目标。

YUE Dream 不会在你刚产生感觉时，突然让你开始打卡填表。AI负责整理，方向由你选择。

## 边界

YUE Dream 是自我探索工具，不是心理治疗、医学诊断或预言工具。梦境不能证明现实事件发生过，也不能替你决定关系、投资、医疗或其他重大事项。

涉及持续噩梦、明显睡眠困扰、创伤反应或安全风险时，请寻求合格的心理健康、睡眠医学或当地紧急支持。
